# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-01

### Added
- Comprehensive project documentation (`README.md`).
- Changelog tracking (`CHANGELOG.md`).
- Version history web page (`version-history.html`) matching the main site's aesthetic.

### Changed
- Standardized directory structure, separating CSS and JS into `assets/css/style.css` and `assets/js/script.js`.
- Moved assets to a structured `assets/images` directory.
